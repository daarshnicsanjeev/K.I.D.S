Step 3: Connect to Gemini Spark

Your school assistant server is active! Follow the steps below to connect your server to Gemini Spark.

🔗 Open Connected Google Apps Script Project

⚙️ Step-by-Step Connection Instructions:

  1. Click Copy Link above to copy your personal server URL.
  2. Click the button below to open Gemini Spark Apps.
  3. In Gemini Spark, go to Connected Apps.
  4. Click Add a custom app.
  5. Paste your copied server link into the Add a custom app link field.
  6. Click Next, then click Authorize to finish!
✨ Open Gemini Spark Apps

📦 Step 1: Download & Upload Skill (SKILL.md):

The skill file contains all reusable dashboard instructions, HTML Canvas rendering rules, single Google Sheet binding, and overdue task calculations:

✨ Open Gemini Spark Skills
  1. Click Download Skill File to save SKILL.md.
  2. Click Open Gemini Spark Skills and upload the SKILL.md file.

⏰ Step 2: Schedule Prompt for Hourly Updates:

Click the prompt below to copy it, then paste it in Gemini Spark to activate hourly updates:

"Using the 'Parent School Intelligence Dashboard' skill and School Portal MCP Server, run this task on an hourly schedule every 1 hour to automatically sync latest school updates, update my Google Sheet, and refresh the live HTML dashboard in-place."

🔓 1-Click Authorization: When triggered, Gemini Spark will only ask for authorization once for the master function!

☑️ Select All Tools Checkbox: When connecting the app in Gemini Spark, click the "Select All" checkbox so the AI has full access to read all school data (Classroom, Drive OCR, Calendar, WhatsApp, and School Portal) automatically.

🏷️ App Name Notice: Please keep the connected app name as School Portal MCP Server so the skill connects automatically.
